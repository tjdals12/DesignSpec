# Login

## Purpose

사용자가 이메일과 비밀번호를 입력해 앱에 로그인하는 진입 화면이다. 비인증 사용자가 보호된 경로에 접근했을 때 이 페이지로 리다이렉트된다.

## Displayed Information

- 앱 로고 또는 서비스명
- `login-form` (이메일/비밀번호 입력 및 로그인 제출 — 에러 메시지 포함)

## Actions

- 이메일과 비밀번호를 입력해 로그인 제출
- 비밀번호 찾기 링크 (선택적 — 레이아웃 공간 확보 용도)

## Layout

페이지 중앙에 카드 형태로 배치된 단일 로그인 영역:
- 상단: 앱 로고 또는 서비스명
- 하단: `login-form` 컴포넌트

## States

- default: 폼이 비어있고 입력 대기 중
- loading: 로그인 요청 처리 중 (버튼 비활성화)
- error: 인증 실패 시 에러 메시지 표시

## Notes

- 이미 로그인된 사용자가 접근하면 앱 메인 화면으로 리다이렉트
- 로그인 성공 후에는 원래 접근하려던 경로로 이동 (없으면 기본 경로)
