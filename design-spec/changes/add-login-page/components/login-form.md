# Login Form

## Role

이메일과 비밀번호를 입력받아 로그인을 제출하는 인증 폼 컴포넌트. 입력 유효성 검사, 제출 상태, 에러 메시지 표시를 담당한다.

## Displayed Information

- 이메일 입력 필드 (레이블 포함)
- 비밀번호 입력 필드 (레이블 포함, 마스킹)
- 로그인 버튼
- 인증 실패 시 에러 메시지
- 비밀번호 찾기 링크

## Actions

- 이메일/비밀번호 입력
- 로그인 버튼 클릭으로 폼 제출
- 비밀번호 찾기 링크 클릭

## Layout

이메일 필드 → 비밀번호 필드 → 로그인 버튼 순의 수직 배치:
- 에러 메시지는 로그인 버튼 위에 표시
- 비밀번호 찾기 링크는 비밀번호 필드 오른쪽 아래에 배치

## States

- default: 필드가 비어있고 입력 대기 중
- loading: 제출 중 — 버튼 비활성화, 스피너 또는 텍스트 변경
- error: 인증 실패 — 에러 메시지 표시, 폼 재입력 가능

## Notes

- 제출 중에는 버튼과 입력 필드를 모두 비활성화해 중복 요청 방지
